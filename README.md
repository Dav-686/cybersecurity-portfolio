# Cybersecurity Portfolio

A learning portfolio documenting practical cybersecurity exercises, network security projects, technical notes, and ongoing professional development.

**Portfolio status:** In progress

## About

This repository records my development in cybersecurity through hands-on laboratory exercises, networking projects, security investigations, and technical study. Reports aim to describe what was actually configured, tested, observed, and verified.

## Focus Areas

- Network security, reconnaissance, and threat detection
- Firewalls, intrusion detection, and intrusion prevention (IDS/IPS)
- Secure network design and segmentation
- Security information and event management (SIEM) with Wazuh
- Endpoint monitoring and file-integrity concepts
- Antivirus testing with ClamAV and the harmless EICAR test file
- Digital forensics fundamentals and evidence integrity
- Web application security fundamentals and OWASP Juice Shop practice
- Linux, Windows, and virtualized lab environments
- Cisco Packet Tracer networking projects

## Tools and Platforms

Tools and platforms used or studied across the labs include Kali Linux, Ubuntu, Windows 10, VMware Workstation, Nmap, tcpdump, Wazuh, Snort, UFW, ClamAV, Docker, OWASP Juice Shop, and Cisco Packet Tracer.

A tool appearing in this list does not imply expert-level proficiency or use in every project.

## Evidence and Reporting Standards

Project reports should include, where available:

- Objective, scope, and lab environment
- Network layout or system context
- Tools and commands used
- Actual outputs and observations
- Sanitized screenshots or other supporting evidence
- Limitations, errors, and unresolved verification
- Lessons learned and relevant references

Practical work, theoretical study, and incomplete assignments are identified separately. Missing evidence is not presented as a successful test.

## Responsible Use and Privacy

All security testing described here is intended for authorized, controlled learning environments. Sensitive information such as passwords, tokens, private contact details, public IP addresses, and identifying network information must be removed or anonymized before publication.
